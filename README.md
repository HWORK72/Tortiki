# Tortiki
мини-игра про тортики
Это уже несерьезный проект сделанный просто от скуки по просьбе девушки, игра про собирание тортиков на конвейере, где можно ставить рекорды и ставить топ1 в лидерборде
Сделан он полностью в main.py для обхода CORS так как тестировал я ботов на cloudflared tunnel и деплоил со своего пк. Если бот не работает - значит он не запущен на моем пк (у меня их несколько и всё время всех включенными держать не могу), тех подкованные ребята смогут взять мой main.py и запустить его в своем PyCharm самостоятельно через BotFather. тут я уже как видно прятал данные в .env
