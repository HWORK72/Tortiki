Аркадная мини-игра с обработкой коллизий на конвейере, глобальной таблицей лидеров и интеграцией Telegram Web App, развернутая через защищенный туннель Cloudflare.

### Архитектурные особенности:
* **Движок физики конвейера:** Реализация динамического спавна объектов, отслеживания скорости ленты и детекции коллизий пользовательского ввода на чистом JavaScript.
* **Глобальный лидерборд:** Серверная фиксация рекордов с защитой от накрутки и выдачей топа лучших игроков через базу данных.
* **Zero-Trust туннелирование:** Развертывание локального бэкенда через Cloudflare Tunnel (`cloudflared`) для безопасного обхода CORS и маршрутизации трафика в Telegram Web Apps без проброса открытых портов.
* **Интеграция с Telegram:** Аутентификация пользовательских сессий через Telegram Bot API с привязкой прогресса к Telegram ID.

### Стек технологий:
* Python 3.12
* Aiohttp / Flask (Серверная часть лидерборда)
* JavaScript / HTML5 Canvas (Клиентский игровой движок)
* Cloudflare Tunnel (Безопасный ingress-шлюз)
* python-dotenv (Конфигурация окружения)
